### 零，油画

油画是一门艺术，基于画家对现实，梦境的感知与表达，形成了以造型，色彩，构图为核心组成的理论体系，以及为了实现它们而发展出来的技法。根据三者的不同侧重点，形成了各种具象的流派。最后使用油性颜料及周边工具将它们呈现在画中。

```mermaid
flowchart LR
  Oil[油画] --> |感知世界|Subject[题材（现实，梦境）]
  Subject --> Theory[理论体系]
  Theory --> Tech[技法]
  Theory --> Genre[流派]
  Tech --> |表达自我|Tool[工具]
  Genre --> |表达自我|Tool
  Tool --> Oil
```

### 一，工具

作画前，需要配置好画架，洗笔筒，调色板，画布。作画中，需要画笔，刮刀，颜料，调色油，稀释剂。作画后，需要上色油，成品框。

```mermaid
flowchart LR
  Tool[工具] --> |作画前|Easel[画架]
  Tool[工具] --> |作画前|Holder[洗笔筒]
  Tool[工具] --> |作画前|Palette[调色板]
  Tool[工具] --> |作画前|Canvas[画布]
  Holder --> |作画中|Brush[画笔]
  Holder --> |作画中|Thinner[稀释剂]
  Canvas --> |作画中|Brush
  Canvas --> |作画中|Paint[颜料（常用色）]
  Palette --> |作画中|ColorOil[调色油]
  Palette --> |作画中|Paint
  Palette --> |作画中|Scraper[刮刀]
  Canvas --> |作画后|Oil[上色油]
  Canvas --> |作画后|Frame[画框]
  Canvas --> |作画中|Scraper[刮刀]
```

#### 1.颜料

基本成分由**颜料粉**与**调色油**（如亚麻籽油）混合研磨而成。

颜料的分类：
1. **传统油画颜料**：慢干，色彩温润通透，适合古典写实和层层罩染。
2. **醇酸树脂油画颜料**：快干，适合快速铺层和户外写生。
3. **水溶油画颜料**：可用水清洗画笔，无需刺激性稀释剂，适合居家创作和初学者。

常用的颜料颜色：
1. 三原色系，深红，土黄，群青
2. 白色系，钛白
3. 黑色系，象牙黑
4. 棕色系，熟褐
5. 补充色系，？

#### 2.油

**调色油**。常用亚麻仁油，加入颜料后留在画面，参与氧化聚合干燥。

**稀释剂**。常用松节油，无味酒精。是挥发性溶剂，不留画面，只负责稀释和清洗。

**上光油**。在油画完成并干透后罩涂上光油，保持画面的光泽度，防止空气侵蚀和积垢。

#### 3.作画工具

**画笔**。用弹性适中的动物毛制成，有硬毛，软毛，各种大小形状，常用：
1. 大号猪鬃平头
2. 中号猪鬃榛形，中号软毛平头，中号软毛榛形
3. 小号软毛圆头，极细勾线笔

**刮刀**。刮刀可用于在调色板上调匀颜料，对画进行修改删除，或者直接用刀作画，常用：
1. 中号菱形调色刀
2. 小号画刀

**画布**。标准的画布，是将亚麻布或帆布紧绷在木质内框上后，用胶或油与白粉掺和并涂刷在布的表面制作而成。常用画框，画板，画布本。

以及常用的：**洗笔筒**，**上光刷**，**调色板**，**画架**，**成品框**。
### 二，理论体系

为了表达出自我对世界的感知，从解决问题的角度出发构建三大理论体系。
#### 1.造型体系

造型体系是油画最基础的底层理论，目的是将三维空间表现在二维画面上，需要解决的问题以及对应的方法论如下：
1. **二维型准**，需要形状感知法，包括：边缘线，轮廓线，正负形。
2. **三维型准**，需要透视学，包括：比例，角度。
3. **结构与动态**，需要解剖学，包括：骨头，肌肉，关节，体块，运动线。
4. **体积感与空间感**，需要明暗法与虚实关系，包括：二分法，明暗交界面，光影。
5. **质感**，需要材质表现法，包括：高光，反光，纹理，笔触。

```mermaid
flowchart LR
  Style[造型] --> |问题1|Precise[型准]
  Style --> |问题2|Struct[结构]
  Style --> |问题3|Feel[感觉]
  Precise --> Shape[形状感知]
  Precise --> Pres[透视]
  Struct --> Anat[解剖]
  Struct --> Pres[透视]
  Feel --> Light[明暗]
  Feel --> Real[虚实]
  Feel --> Mate[材质表现]
```
#### 2.色彩体系

色彩理论的目的是将光色关系、色彩空间与情感表现组织在二维画面上，需要解决的问题以及对应的方法论如下：
1. 色准，需要色彩感知法，包括：色相，明度，纯度，冷暖。
2. 色调统一，需要色调法，包括：主色调，纯度对比，黑白灰。
3. 色彩塑造，需要造型体系。

```mermaid
flowchart LR
  Color[色彩] --> |问题1|Precise[色准]
  Color --> |问题2|Tone[色调统一]
  Color --> |问题3|Feel[色彩塑造]
  Precise --> Catch[色彩感知]
  Tone --> Catch[色彩感知]
  Tone --> Tone.[色调]
  Feel --> Style[造型体系]
```
#### 3.构图

构图的目的是将视觉元素与形式关系组织在二维画面上，需要解决的问题以及对应的方法论如下：
1. 定位，需要基本单位，包括：框架。
2. 视觉中心，需要主次，虚实关系，包括：。
3. 节奏，需要动势法，组织法，包括：方向，视线，路径，疏密，间隔。
4. 空间层次，需要层次法，包括：前景，中景，背景，遮挡，透视，空气远近。

### 三，技法

按作画逻辑，分成四个大阶段。大部分直接画法（湿画法），调整时采用少部分间接画法（罩染）。
#### 1.起型

**目的**：
确定构图、比例、透视、动态和大形。

**方法**：
用单色薄涂或线稿，先定大位置、大结构，不抠细节。

**理论基础**：
构图，造型。
#### 2.铺色

**目的**：
建立整体色调、黑白灰和冷暖关系。

**方法**：
大笔薄涂，概括色块，趁湿衔接，保持整体。

**理论基础**：
色彩。
#### 3.深入

**目的**：
塑造体积、结构、质感、空间和细节，同时不破坏整体。

**方法**：
压暗提亮，丰富色彩，局部塑造，并不断与整体比较。

**理论基础**：
造型，色彩，构图。
#### 4.调整

**目的**：
回到整体，统一色调、明暗、冷暖、虚实和主次。

**方法**：
远看、眯眼、对比，加强或减弱；少部分罩染统一画面。

**理论基础**：
造型，色彩，构图。

```mermaid
flowchart LR
    Oil[油画] --> |阶段1| Mold[起型]
    Mold --> |阶段2| Apply[铺色]
    Apply --> |阶段3| Deep[深入]
    Deep --> |阶段4| Adjust[调整]
    
    Mold --> Style[造型] & Compos[构图]
    Apply --> Color[色彩]
    Deep --> Style & Compos & Color
    Adjust --> Style & Compos & Color
```

### 五，具象流派

油画的流派分为两大类。第一类是以客观再现为主；第二类是以主观表现为主。
#### 1.客观再现

**参照世界**：
- 文艺复兴时期
- 古典派，新古典派，学院派
- 写实主义
- 印象主义
#### 2.主观表现

**创造世界**：
- 巴洛克艺术
- 洛可可艺术
- 浪漫主义
