#### 1.书籍

**思维：**
- 像艺术家一样思考
- 素描之道
- 刻意练习

**造型：**
1. 人体
   - 巴尔格素描教程
   - 艺用人体结构
   - 人体绘画，设计与创造
   - 彰显生命力
2. 透视
   - 透视如此简单
   - 空间透视图解
   - 美国绘画透视完全教程
3. 动物
   - 国际插画大师惠特拉奇的动物画教程（系列）
     - 艺用生物解剖

**色彩：**
- 色彩感知学
- 色彩与光线
- 色彩与光影
- 色彩如何改变视觉

**构图：**
- 色彩与构图
- 图像（色彩如何改变视觉，同作者）
- 想象力，构图与创作思维
- 构图的艺术

**油画：**
- 油画材料与技法
- 油画技法难题详解
- 欧洲绘画大师技法和材料
- 油画大师的奥秘
- 油画自学大师课（系列）
  - 西方学院派油画教程
  - 油画的光与色
  - 油画肖像经典技法
  - 油画风景写生与创作
  - 油画大师的20堂主题课
  - 写实油画入门

**CG**：
- CG造型基础与创作（系列）
  - 入门篇
  - 进阶篇
